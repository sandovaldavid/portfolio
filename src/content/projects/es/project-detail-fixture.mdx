<CaseStudySection eyebrow="FIXTURE DE DESARROLLO" title="Una sola página que ejercita todas las capacidades de Project Detail">
  Este **no es un proyecto real del portfolio**. Existe únicamente en desarrollo para revisar el sistema de contenido de Project Detail con todos los recursos opcionales y primitives MDX habilitados al mismo tiempo.
</CaseStudySection>

<CaseStudySection eyebrow="PROBLEMA" title="Un sistema compartido necesita un lugar seguro para probar contenido opcional">
  Los proyectos reales omiten intencionalmente los recursos que no poseen. Eso dificulta inspeccionar visualmente todas las combinaciones de repositorios, documentación, live demo, package, galerías, video y diagramas desde una sola ruta.

  Este fixture proporciona esa ruta sin añadir evidencia falsa a producción.
</CaseStudySection>
