<CaseStudySection eyebrow="DEVELOPMENT FIXTURE" title="One page that exercises every Project Detail capability">
  This is **not a real portfolio project**. It exists only in development so the Project Detail content system can be reviewed with all optional resources and MDX primitives enabled at the same time.
</CaseStudySection>

<CaseStudySection eyebrow="PROBLEM" title="A shared system needs a safe place to test optional content">
  Real projects intentionally omit resources they do not have. That makes it difficult to visually inspect every combination of repositories, documentation, live demo, package links, galleries, video and diagrams from a single route.

  This fixture provides that route without adding fake production evidence.
</CaseStudySection>
