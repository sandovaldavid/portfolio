<CaseStudySection eyebrow="PROBLEM" title="Agent tooling needs durable context beyond one process">
	The fixture models a local MCP service that accepts requests from several agent clients,
	persists durable records and exposes optional retrieval integrations. The narrative deliberately
	starts from the system boundary instead of a visual product surface.
</CaseStudySection>
