## Current status

v2.0.0 is the next major version of the portfolio and is still in development. The release pull request remains open while I finish the remaining work. That PR prepares the release, but v2.0.0 is not published yet. Until it is merged and the production deployment is verified, v1.0.0 remains the released version.

## What has changed so far

- **Positioning**: The portfolio now starts with who I am as a Software Engineer, then uses technologies and domains as supporting evidence rather than as the identity itself.
- **Professional experience**: Experience pages explain the kind of systems I work on, the engineering problems I handle and how I validate changes, without exposing proprietary implementation details.
- **Project case studies**: Project pages give more context about the problem, technical decisions, trade-offs, validation and what a visitor can actually inspect.
- **Identity system**: The visual language, typography, tokens, logo assets and iconography are being aligned with the shared Figma Identity System instead of maintaining a separate visual direction in code.
- **English and Spanish**: Public content, metadata and navigation are maintained in both languages, with wording adapted for each audience instead of relying on literal translation.
- **Accessibility and responsive behavior**: Keyboard navigation, focus states, reduced-motion behavior and responsive layouts have been tightened across the main routes.
- **SEO and content metadata**: Canonical metadata, hreflang, structured data and page-level descriptions have been reviewed so the public metadata matches the content people actually see.
- **Research**: The research section now reflects the current thesis direction and makes its open questions clear instead of presenting an earlier model choice as settled.

## What is still being finalized

Before v2.0.0 is released, I still need to finish the page-specific Open Graph previews and route mapping, complete the EN/ES content and metadata review, and run the final build, E2E, accessibility and performance checks across the main routes.

The release pull request should remain open until that work is complete and the production deployment can be verified.

## Why this is a major version

This is not only a visual refresh. v2.0.0 changes how the portfolio explains my work: less emphasis on effects or stack lists, more emphasis on professional context, technical judgment, evidence and readable engineering stories.
