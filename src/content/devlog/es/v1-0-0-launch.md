## Qué estableció v1.0.0

v1.0.0 es la primera versión formal del portfolio actual. Estableció una base estable antes de comenzar la revisión mayor de v2.0.0.

El objetivo era simple: tener un sitio fiable, accesible y mantenible antes de ampliar el contenido y el sistema visual.

## Base de ingeniería

- **Base frontend**: Astro con TypeScript estricto y una estructura Feature-Sliced Design que mantiene explícita la dirección de dependencias.
- **Estilos y temas**: Tailwind CSS con preferencias de tema claro, oscuro y sistema.
- **Accesibilidad**: Navegación por teclado, enlace para saltar al contenido, soporte para movimiento reducido y validaciones automatizadas.
- **Calidad**: Cobertura E2E con Playwright, Lighthouse CI, CodeQL y validaciones de bundle dentro del flujo de entrega.
- **SEO**: Metadatos canónicos y datos estructurados para las principales rutas públicas.
- **Despliegue**: Integración del despliegue en Vercel con el flujo del repositorio.

## Qué cambió después de v1

La primera versión todavía reflejaba una dirección visual anterior, más centrada en efectos. Sirvió como punto de partida, pero no comunicaba mi trabajo con la claridad que buscaba. Por eso v2.0.0 pone menos énfasis en la novedad visual y más en contexto profesional, evidencia, casos de estudio legibles y un sistema de identidad coherente.
